# 📰 The Dragon News Hub

The Dragon News Hub is a modern and fully responsive news web application that provides users with an engaging news-reading experience. Users can browse news by category, securely authenticate using Firebase, and access protected news details pages. The project demonstrates modern React development with authentication, routing, state management, and responsive UI design.

---

## 🌐 Live Demo & Links

- 🚀 **Live Website:** https://the-dragon-news-hub.web.app/category/0
- 📂 **GitHub Repository:** https://github.com/mdalamin0/The-Dragon-News-Hub

---

# 🛠️ Main Technologies

- React.js
- React Router DOM
- Context API
- Tailwind CSS
- DaisyUI
- Firebase Authentication

---

# ✨ Key Features

- 📰 Browse news through category-based filtering.
- 🔐 Secure authentication with Email/Password, Google, and GitHub.
- 🛡️ Protected routes with automatic redirection after successful login.
- 📄 Dynamic news details page for viewing complete articles.
- 📅 Live date display and breaking news marquee.
- ⚡ Fast, responsive, and user-friendly interface.
- 📱 Fully responsive across desktop, tablet, and mobile devices.

# ⚙️ Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/mdalamin0/The-Dragon-News-Hub.git
```

### 2️⃣ Navigate to the project directory

```bash
cd The-Dragon-News-Hub
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Configure Firebase

Create a `.env.local` (or `.env`) file in the project root and add your Firebase configuration.

```env
VITE_API_KEY=
VITE_AUTH_DOMAIN=
VITE_PROJECT_ID=
VITE_STORAGE_BUCKET=
VITE_MESSAGING_SENDER_ID=
VITE_APP_ID=
```

### 5️⃣ Run the development server

```bash
npm run dev
```

### 6️⃣ Open your browser

```text
http://localhost:5173
```

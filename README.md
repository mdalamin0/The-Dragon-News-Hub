# 📰 The Dragon News Hub

A modern, responsive news web application built with **React.js** that delivers a seamless and engaging news-reading experience. The platform features category-based news filtering, secure user authentication, protected routes, and dynamic news details pages, providing users with an intuitive and performance-focused interface across all devices.

# 🚀 Features

- 📰 Browse news through **category-based filtering**
- 🔐 Secure authentication using **Email/Password, Google, and GitHub**
- 🛡️ Protected routes with automatic redirection after successful login
- 📄 Dynamic news details page with extended article viewing
- 📅 Live date display
- 📢 Breaking news marquee
- ⚡ Fast and responsive user interface
- 📱 Fully responsive across desktop, tablet, and mobile devices

---

# 🛠️ Tech Stack

### Frontend

- React.js
- React Router DOM
- Context API
- Tailwind CSS
- DaisyUI

### Authentication

- Firebase Authentication
  - Email & Password
  - Google Sign-in
  - GitHub Sign-in

### Deployment

- Firebase Hosting

---



# 💡 Challenges

- Implementing protected routes while preserving the user's intended destination after authentication.
- Managing authentication state efficiently with Context API.
- Building a fully responsive layout for desktop, tablet, and mobile devices.
- Handling dynamic routing for category-based news and article details.
